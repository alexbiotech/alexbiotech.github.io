How I get agents to finish the work

I want one group of agents to do the work and another to inspect it. The first group gathers material, makes a version, and revises it. The second checks the actual result against the same goal. What I expect at the end is something I can use and inspect. Explaining the approach should lead to carrying out the remaining work.

At the beginning, I try to define the question, goal, constraints, and acceptance criteria. What should be delivered? Which facts can it use? What would count as finished? Those decisions shape the work. If the goal needs discussion, that discussion should gradually lead to a specific object to work on.

Let reviewers inspect the result

I like to assign execution and review to different agents. The agents doing the work gather material, make a version, and revise it. Reviewers use the same goals to examine the actual artifact and original material. That gives them a chance to find problems the agents doing the work did not notice.

For a personal website, opening a page is only one check. Can a visitor find the content? Does the writing match my experience? Is it readable on a phone? Those questions require looking at the pages. Review comments need to identify the location and consequence of a problem so the work can continue.

Boris Cherny’s discussion of giving agents verification feedback relates to this concern. Continuing a task requires information about the current result so the agent can decide what to correct next. Original

Long tasks also need a way for whoever takes over to recover the goal, reasons for decisions, and unresolved questions. Anthropic’s account of context management offers approaches such as structured notes. Original

Addy Osmani argues for clear stopping conditions and an independent check of the result. That fits what I want from sustained agent work. Even after the checks pass, I still need to look at the actual result. Original

I am also willing to ask another model to look for counterexamples and omissions. Another review still needs access to the evidence. Reading only the first agent’s summary can carry the same omission forward. A disagreement should lead to further examination of sources, data, or observed behavior.
