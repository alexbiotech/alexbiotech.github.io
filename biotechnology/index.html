Biotechnology

I work on programmable biological systems, using RNA, proteins, and cellular signals to connect information with function.

From input to function

These are connected parts of a design, rather than a fixed order for every experiment.

  1. 01

    Sense

    Read a measurable cellular signal as an input to the system.

  2. 02

    Compute

    Combine molecular inputs to determine when a response should occur.

  3. 03

    Translate

    RNA structure, upstream open reading frames, and response elements connect design choices with protein output.

  4. 04

    Deliver

    Follow loading, cell entry, release, and intracellular function as distinct parts of the path.

Research directions

Programmable RNA

I study how RNA can read cellular signals and control protein output. My work on PROMITAR explores how RNA switches can connect signal sensing, logic, and cell classification.

Question, system, and readout
Question
Can a cellular signal control when an RNA is translated?
System
microRNA-responsive elements and RNA translation-control circuits.
Readout
Protein output, logic responses, and cell classification.
Related work
PROMITAR · 2023

Cell state and biological data

Transcriptomic, single-cell, and spatial data can reveal regulatory features of cell state. I combine those data with computational analysis and ask which features can become useful engineering inputs.

Question, system, and readout
Question
Which regulatory elements distinguish different cell states?
System
Transcriptomic, single-cell, and spatial analysis, with computational modeling.
Readout
State classification, candidate regulators, and synthetic promoter behavior.
Related work
SPECIFIC · 2025

Delivery that leads to function

A delivery system has to do more than reach a cell. I am interested in how RNA is carried, released, and put to work, including research on human ARC-derived particles.

Question, system, and readout
Question
What would show that RNA has reached the place where it can function?
System
The connected path through loading, entry, release, and cellular function.
Readout
Separate evidence for distribution, cellular availability, expression, and intended function.
